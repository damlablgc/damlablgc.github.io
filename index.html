Explainable AI · Robotics

RoboSLMExplainer

Simulates an HC-SR04 ultrasonic sensor with realistic sensor noise, filters readings with a sliding-window average, detects approach/retreat trends, and uses a locally-run Phi-3 Mini model (via Ollama) to explain every navigation decision in plain English — built for auditable, offline-capable robot reasoning.

Python · Phi-3 Mini · Ollama GitHub ↗
Open case

No real HC-SR04 hardware was on hand, so the sensor is software-simulated with injected noise rather than idealized readings — the goal was to test the filtering logic under realistic conditions, not a clean signal.

A single raw reading is noisy enough to trigger false approach/retreat calls. A sliding-window average smooths that out before the decision layer sees it, trading a small amount of latency for fewer false triggers.

Explanations run through Phi-3 Mini via Ollama, locally — no cloud API call per decision. That keeps the robot's reasoning auditable offline and removes a network dependency from a real-time control loop.

Validated with 75/75 pass-fail tests across simulated approach/retreat scenarios.

Medical Imaging · ML

Melanoma Recall Optimization

Reframed a heavily imbalanced 7-class dermatoscopy dataset (HAM10000) as a binary melanoma-vs-rest problem to prioritize catching dangerous cases, using class weighting and EfficientNetB0 transfer learning.

Accuracy~89%63%
Recall (melanoma)~0%92%
Missed cases223 / 22317 / 223
Kaggle GPU · EfficientNetB0 GitHub ↗
Open case

HAM10000 has 7 skin-lesion classes, heavily imbalanced. Optimizing accuracy across all 7 rewards the model for ignoring the rare, dangerous one. Collapsing it to melanoma vs. rest forces the objective to match the actual cost of the error: missing a melanoma case matters more than misclassifying two benign types against each other.

Melanoma is still the minority class in the binary split, so unweighted cross-entropy would still favor "rest." An ~8x class weight on melanoma penalizes those misses hard enough during training to move the decision boundary.

Early stopping watched val_recall, not val_loss. Val_loss would have stopped training at the point of best overall fit, which is not the same point as best melanoma recall — those two curves diverge under class weighting.

Result after 7 epochs: 92% melanoma recall, 17 missed cases out of 223, against a naive baseline that misses all 223 while reporting ~89% accuracy.
